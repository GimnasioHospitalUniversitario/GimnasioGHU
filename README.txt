# Landing Page — Gimnasio Hospital Universitario (GHU)

Landing page base construida con:

- HTML5
- CSS3
- JavaScript básico
- Bootstrap 5.3.3
- Bootstrap Icons

## Archivos

- `index.html` — estructura completa de la landing.
- `styles.css` — estilos e identidad visual GHU.
- `app.js` — calculadora de tarifas, navegación y botón volver arriba.

## Importante

La información de servicios, horarios, requisitos, contacto y tarifas fue tomada del tríptico proporcionado para este proyecto.

La página usa Bootstrap desde CDN, por lo que requiere conexión a Internet para cargar Bootstrap y Bootstrap Icons.

## Imágenes

La primera versión utiliza fondos y elementos gráficos CSS para que funcione inmediatamente.
Se recomienda posteriormente sustituir el fondo del hero y el bloque de torneos por fotografías reales del gimnasio.
